Privacy Policy

Last updated 10 October 2026.

The short version

This site is static HTML. It has no advertising, no cookies, and no login. It counts visits with Cloudflare Web Analytics, which sets no cookies and does not identify you.

What that means in detail

Cookies. This site sets none, and neither does its analytics.

Analytics. Cloudflare Web Analytics, added 10 October 2026. It counts page views and records which page was visited, the referring site, the country, the browser and device type, and how fast the page loaded. Cloudflare states that it uses no cookies or local storage for this and does not fingerprint visitors by IP address or user agent. We see totals, not individuals.

Advertising. None at present. If advertising is added in future, this page will be updated before any ad code goes live, and it will name the ad provider and say what data that provider collects. Advertising networks generally do set cookies and process data for personalised ads; when that applies here, it will be described here.

Third-party requests. The pages load one font file from this same domain. The only request to another server is the analytics script from Cloudflare (static.cloudflareinsights.com), which reports the visit as described above. No font CDN, no ad server, no image host. One tutorial page shows a YouTube video, and it loads nothing from YouTube until you press its play button. Once you press play, the video comes from YouTube’s privacy-enhanced player (youtube-nocookie.com) and YouTube’s own privacy policy applies to that video.

Server logs. The site is served by Cloudflare, which, like all hosting providers, records ordinary technical request data such as IP address, user agent and the URL requested. This is standard operational logging, not something this site reads or analyses.

Email. If you email us, we have your email and whatever you wrote, for as long as needed to reply and keep a record of corrections. It is not added to any list, because there is no list.

Children. This site is written for adults buying or making gifts for babies. It is not directed at children and collects nothing from anyone.

Your rights

Since we hold no data about individual visitors, there is nothing to access, correct, export or delete. If you have emailed us and want that email deleted, ask and it will be.

Changes

Material changes — in practice, that means adding advertising or any new tracking — will be reflected here with a new date at the top, before the change goes live.
