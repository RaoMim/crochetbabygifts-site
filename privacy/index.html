Privacy Policy

Last updated 30 July 2026.

The short version

This site is static HTML. It has no analytics, no tracking scripts, no advertising, no cookies of its own, and no login. There is nothing to opt out of because nothing is being collected.

What that means in detail

Cookies. This site sets none.

Analytics. None. We do not currently know how many people read this, which is an odd feeling but an honest one.

Advertising. None at present. If advertising is added in future, this page will be updated before any ad code goes live, and it will name the ad provider and say what data that provider collects. Advertising networks generally do set cookies and process data for personalised ads; when that applies here, it will be described here.

Third-party requests. The pages load one font file from this same domain. Nothing is requested from any other server — no font CDN, no script host, no image host. Loading a page on this site does not tell any third party that you did.

Server logs. The site is served by a hosting provider which, like all hosting providers, records ordinary technical request data such as IP address, user agent and the URL requested. This is standard operational logging, not something this site reads or analyses.

Email. If you email us, we have your email and whatever you wrote, for as long as needed to reply and keep a record of corrections. It is not added to any list, because there is no list.

Children. This site is written for adults buying or making gifts for babies. It is not directed at children and collects nothing from anyone.

Your rights

Since we hold no data about visitors, there is nothing to access, correct, export or delete. If you have emailed us and want that email deleted, ask and it will be.

Changes

Material changes — in practice, that means adding analytics or advertising — will be reflected here with a new date at the top, before the change goes live.

Questions: see contact.
